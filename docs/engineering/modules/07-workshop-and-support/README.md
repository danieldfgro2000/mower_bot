# Module 07 — Workshop and support

<a id="document-overview"></a>

**Summary:** Module 07 plans the workshop resources for a staged propulsion
check: an owner-fabricated guarded bench fixture, budgeted meters, handling
supports, fabrication consumables, spares, and starter PPE. It does not include
a dynamometer or direct torque measurement; torque remains a pre-calculation.
Several items are owner-reported and marked reused pending verification.

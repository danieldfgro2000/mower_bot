# Module 06 — Safety controls and sensors

<a id="document-overview"></a>

**Summary:** Module 06 covers the independent stop system, normal operator
control, interlocks, status, instrumentation, and logging. The owner intends
mobile-app-only normal control and a general hardware E-stop, but neither the
loss-of-link stop nor the E-stop design is verified. Requirements remain on
hold; safety scope stays distinct from Module 05 power distribution.

cross-references. The app is not the independent emergency stop.

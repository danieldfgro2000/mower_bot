# Module 02 — Drive train

<a id="document-overview"></a>

**Summary:** Start with the motor, inspect its price and data, then follow
the mounting path to the track. HPM5000B, EZ-A48500 and FDB 13 C are the
costed candidates; custom reduction and brake installation remain unpriced.
Neither these nor non-additive alternatives are approved or installed selections.

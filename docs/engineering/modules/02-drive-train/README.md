# Module 02 — Drive train

<a id="document-overview"></a>

**Summary:** Module 02 covers traction motors, controllers, holding brakes,
output support, and reduction hardware. Current direction is controller-based
motor braking for dynamic deceleration and a default-applied mechanical brake
for stationary holding. Motor, controller, ratio, and brake performance remain
unqualified.

# Engineering agent guide

This folder contains MowerBot-specific instructions for agents maintaining
engineering sources. It is not a technical specification or a presentation
source.

| Need | Start here |
| --- | --- |
| Route an engineering/BOM task to its owner | [Agent index](agent-index.md) |

| Change prices, evidence or linked cost tables | [Updating linked costs](updating-linked-costs.md) |

Use the [technical index](../technical/README.md) for authoritative
engineering details and the [presentation pages](../presentation/README.md)
for concise generated summaries. Do not copy technical facts into agent
guidance; link to their owning source.
